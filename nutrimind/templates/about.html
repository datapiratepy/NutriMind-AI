How NutriMind AI works

A transparent look at the architecture: multi-agent orchestration, retrieval-augmented generation, IBM Granite, and strictly deterministic mathematics.

Agentic AI, not a chatbot

A single-prompt chatbot pushes every request through one model call. NutriMind instead runs a Coordinator that classifies each request — with deterministic rules first, IBM Granite only for ambiguous cases — and hands it to one of four specialists. Every answer tells you which agent handled it and why.

Specialist agent runs its tools (retriever, nutrition service, food table) — every invocation is listed in the response

IBM Granite writes the language around verified numbers and retrieved evidence

Retrieval-Augmented Generation (RAG)

Factual questions are answered against your nutrition documents, not just model memory:

1 · Ingest PDF → text per page → ~800-character chunks with page metadata → embeddings → ChromaDB vector store
2 · Retrieve your question is embedded and the top-5 most similar chunks are fetched
3 · Threshold chunks below 0.35 similarity are rejected — weak matches are never dressed up as evidence
4 · Generate Granite answers from the passages, citing them as [1], [2] with filename + page
5 · Label if nothing passed the threshold, the answer is visibly marked General knowledge — not from your documents

IBM watsonx.ai & Granite

watsonx.ai is IBM's enterprise AI platform. NutriMind calls the granite-4-h-small chat model and granite-embedding-278m-multilingual through the official Python SDK, with retries, typed error translation and a zero-token startup health check. Without credentials the app switches to a deterministic demo engine — same architecture, canned language.

ChromaDB & embeddings

Embeddings turn text into vectors whose distance reflects meaning. Each embedding provider (watsonx / local / hash-fallback) writes to its own Chroma collection so incompatible vector spaces never mix. Every chunk stores filename, page, chunk number, upload date, provider and document ID — that's where the citations come from.
