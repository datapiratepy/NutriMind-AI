# Archive — IBM SkillsBuild internship submission material

These documents belong to the internship submission that NutriMind AI was
originally built for. That phase is complete. They are kept for provenance, not
because they describe the current product.

They were moved out of `docs/` because the repository is now a production
application rather than a submission: a reader evaluating the engineering
should reach architecture and setup documentation first, not a presentation
outline or a screenshot checklist.

**Relative links inside these files still point at the old `docs/<name>.md`
paths and are not maintained.**

Current documentation lives one level up:

| [AGENTS.md](../AGENTS.md) | Agent contracts and the streaming event protocol |
